# Functional / Declarative Kotlin Refactor — Full Sweep

## Goal

Rewrite all 64 Kotlin source files across `domain`, `infrastructure`, `app`, and `tests` in a functional / declarative Kotlin style:

- **Top-level functions and extension functions** over single-method interfaces and `Impl` classes
- **`arrow.core.Either<DomainError, T>`** instead of nullable returns and swallowed exceptions
- **DSL builders** (`crawlPipeline { }`, `crawl { }`, `securityConfig { }`, `businessRules { }`) for ≥3 args or nested structure
- **Value classes + immutable data** everywhere; no `Instant.now()` defaults in data class constructors
- **Functional naming** — verbs for actions, `-ing`/`-ed` for state, no `Service`/`Repository`/`Controller`/`Impl`/`Dto`/`Helper`/`Manager`/`Factory`/`Builder` suffixes
- **`@DslMarker`** to scope builder blocks
- **Spring `@RestController` retained**, handlers moved to extension functions, class renamed `*Routes`

Same external behavior, every file reads as functional Kotlin idioms: `map`, `flatMap`, `let { }`, `.fold`, `forAll`, `either { }`, `Validated`, `Either.zip`.

### Infrastructure (`infrastructure/src/main/kotlin/ru/wbparser/infra/`)

**pipeline/** — DSL + Flow + Either:
- `CrawlPipeline.kt` → DSL `fun crawlPipeline(block: PipelineBuilder.() -> Unit): Pipeline`. `Pipeline` is a data class with `run(Session): Either<DomainError, Crawled>`, internally `channelFlow { }` + `flatMapMerge(concurrency)` + per-stage `retry { }`.

- **new** `pipeline/PipelineDsl.kt` — `@DslMarker CrawlDsl`, `PipelineBuilder` with `download { }`, `parse { }`, `validate { }`, `enrich { }`, `save { }`, `stopWhen { }`, `concurrency(n)`, `batchSize(n)`, `dedup(seen)`, `stats(s)`

- `CrawlSession.kt` → `Session.kt`; `Dedup` → `data class SeenUrls(urls: MutableSet<String>)`
- `CrawlStatistics.kt` → `CrawlStats.kt` (immutable; `record*` extensions return new state)
